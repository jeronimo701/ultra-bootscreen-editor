# Ultra Bootscreen Editor

Редактор заставок UltraNX для Windows: открой картинку, выбери кадр, добавь текст и получи BMP в нужном для консоли формате.

**Windows 10/11 x64 · версия 1.0.0 · автономный EXE**

[Скачать 1.0.0](https://github.com/jeronimo701/ultra-bootscreen-editor/releases/tag/v1.0.0) · [Подробная инструкция](DETAILS.ru.md) · [Manager для Switch](https://github.com/jeronimo701/ultra-bootscreen-manager) · [Проблемы](https://github.com/jeronimo701/ultra-bootscreen-editor/issues)

![Окно редактирования заставки](docs/screenshots/editor.png)

*Настоящий интерфейс Windows, снятый встроенным режимом `--capture`. Это редактор на ПК, а не окно на Switch.*

## Что умеет

- Открывать PNG, JPEG, BMP, GIF (первый кадр) и TIFF, в том числе по прямой ссылке.
- Кадрировать под 16:9, перемещать и масштабировать изображение.
- Добавлять текст и ник с настройкой шрифта, цвета и положения.
- Показывать предпросмотр и обрабатывать несколько изображений за раз.
- Экспортировать повёрнутый BMP 720×1280, 32 bpp, без сжатия.

## От картинки до заставки

1. Скачай EXE из [Releases](https://github.com/jeronimo701/ultra-bootscreen-editor/releases/tag/v1.0.0). Устанавливать .NET не нужно.
2. Открой `UltraBootscreenEditor.exe`, перетащи картинку в окно.
3. Подбери кадр мышью и колесом. При желании включи текстовые слои.
4. Проверь «Предпросмотр» и нажми «Сохранить BMP».
5. Передай файл [Ultra Bootscreen Manager](https://github.com/jeronimo701/ultra-bootscreen-manager) либо вручную установи как `bootloader/res/bootscreen.bmp` после резервного копирования SD.

Горячие клавиши: **Ctrl+O** — открыть, **Ctrl+S** — сохранить, **Esc** — закрыть предпросмотр.

## Пакетная обработка

Выбери несколько файлов и папку вывода. Кадрирование выполняется по центру; включённые текстовые слои добавляются ко всем изображениям. Существующие файлы не перезаписываются — при совпадении добавляется суффикс.

## Разработка и статус

Исходники на C#/.NET; `build.ps1` использует .NET SDK 10 и создаёт автономный EXE. [Проверки](VALIDATION.md) описывают формат BMP, ориентацию, текст и защиту файлов. Сборка не подписана; тест на физической Switch отдельно не подтверждён.
