# Сторонние компоненты

Приложение написано на C# / Windows Forms. Автономный Windows x64 EXE содержит
.NET runtime 10.0.12 и Windows Desktop runtime 10.0.12 от .NET Foundation / Microsoft.
SDK сборки: 10.0.401. Отдельные NuGet-библиотеки приложения не используются.

Исходные лицензионные уведомления из использованных runtime-пакетов:

- [Лицензия .NET runtime](licenses/microsoft.netcore.app.runtime.win-x64-LICENSE.TXT).
- [Сторонние уведомления .NET runtime](licenses/microsoft.netcore.app.runtime.win-x64-THIRD-PARTY-NOTICES.TXT).
- [Лицензия Windows Desktop runtime](licenses/windowsdesktop-LICENSE.txt).

Эти лицензии относятся к компонентам runtime, а не назначают лицензию авторскому
коду Editor. Отдельная лицензия на код автора пока не выбрана.

Скриншот с заставкой использует изображение из предоставленного автором проекта
Ultra Bootscreen Manager. Названия, персонажи и товарные знаки принадлежат своим
правообладателям; отдельная свободная лицензия на изображения не назначается.
Системные шрифты и сама Windows не распространяются с приложением.

Связанные проекты: [dotnet/runtime](https://github.com/dotnet/runtime),
[dotnet/winforms](https://github.com/dotnet/winforms).
