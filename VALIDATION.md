# Проверка релиза 1.0.1

Дата: 26 ноября 2026.

- SDK 10.0.401; автономный Windows x64 single-file EXE с .NET и Windows Desktop runtime 10.0.12.
- Версии сборки и файла: 1.0.1.0; версия продукта: 1.0.1 с идентификатором исходного commit.
- 11 встроенных self-test PASS: заголовок и размер BMP 720×1280/32 bpp, полный pixel round-trip 1280×720, ориентация BMP/PNG, кадрирование, текстовые слои, пакетные коллизии и защита исходников, сохранность файла при неудачном экспорте, неверные изображения/URL, локальная HTTP-загрузка и предел размера, экспорт демонстрационной картинки.
- Контрольный BMP побайтно совпал с результатом оригинального EXE 1.0.0. Его SHA256 перед запуском сверена с прежним релизом.
- Тестовые файлы создавались в отдельной папке. HTTP-тест использует только loopback и случайный порт; настоящие SD-карты и пользовательские изображения не менялись.
- Интерфейс отрисован встроенным `--capture`; русские надписи просмотрены, квадраты вместо букв не обнаружены. В заголовке окна отображается 1.0.1.
- Для готового EXE опубликована SHA256 в файле контрольных сумм релиза. Лицензии собственного кода и runtime прилагаются отдельно.

Чистка кода: общее название и версия в AppInfo, общий метод создания шрифтов. Формат BMP и алгоритмы обработки не изменялись.

Не проверялись физическая Switch, все версии UltraNX, чистая Windows и все диалоги/DPI. Цифровой подписи у EXE нет. Editor не прошивает консоль и не меняет SD автоматически.
