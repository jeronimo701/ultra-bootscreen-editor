# Проверка релиза 1.0.0

Дата: 2026-10-21.

- Повторный `dotnet publish -c Release -r win-x64`: SDK 10.0.401, автономный single-file EXE с runtime 10.0.12. Сборка прошла, сообщений warning/error в логе не обнаружено.
- EXE: FileVersion 1.0.0.0, ProductVersion 1.0.0; размер 51 668 721 байт.
- SHA256: `5cacbc183fa941c09476c2d20cd218ac38e3003f03dc0d3e4a2da8e655dc79e0`.
- 11 встроенных self-test PASS: BMP 720×1280/32 bpp и точный заголовок оригинала, полный pixel round-trip 1280×720, ориентация, кадрирование, текст, пакетные коллизии, защита исходников/экспорта, отказ неверному изображению/URL, локальная HTTP-загрузка и ограничение размера, экспорт демонстрационной картинки.
- HTTP-тест использует только loopback на случайном порту. Внешние сайты для теста не загружались.
- Два вызова встроенного --capture завершились с кодом 0; PNG просмотрены перед публикацией. Это отрисовка формы на Windows, не подтверждение ручного прохождения всех диалогов.
- Gitleaks 8.30.1: подготовленная папка без находок. Проверка сканером не гарантирует отсутствие всех возможных секретов.
- Функциональные C#-исходники сохранены; версия 1.0.0 закреплена явно в csproj, путь SDK в build.ps1 заменён на переносимый dotnet из PATH. Обновлена только документация публикации.
- Оригинальная папка не изменена. Локальные obj/bin, тестовые файлы и прежний ZIP не публиковались.

Не проверены: физическая Switch, все версии UltraNX, все разрешения/DPI Windows,
ручное прохождение всех диалогов и установка на чистую Windows. Цифровой подписи
у приложения нет. Editor не прошивает консоль и не меняет SD автоматически.
